Product

When resources are scarce, should an individual cooperate or compete? I used agent-based modeling (ABM) to simulate how survival strategies evolve in a closed population under resource fluctuation — from hawkish grabbing to dovish sharing, across factions, population sizes, and resource levels. It not only validates game-theory intuitions but also surfaced counterintuitive patterns of group behavior.

Engineering

A full state machine built with Python + the Mesa framework, simulating individual decisions (grab / share / reproduce / die). Parameterized experiments cover faction ratios, total resources, population size and more — reproducible and extensible. Findings were written up as a working paper; the code is open source.
